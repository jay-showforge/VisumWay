# VisumWay v0.2.5 — Windows x64 beta

VisumWay gives a compatible desktop agent access to app controls, window
frames and local evidence through one installation.

- Read Windows control labels, roles, state and bounds with `inspect_window`.
- Follow one selected window with a buffered watch. In a signed-in Codex
  test, it retained a 552 ms visual change that occurred between requests.
- Reuse the installation in another compatible agent. The installing
  agent keeps notification ownership, and automatic wakes are opt-in.

In two matched Windows Calculator trials, signed-in Codex completed the
same task in **23.3 s with direct control reads** and **34.3 s using
screenshots**, about **32% less time** for that task.
[Benchmark method](../docs/BENCHMARK.md).

The Windows x64 bundle installs offline and requires Python 3.9 or newer.
Give the bundle or repository to your agent and say, “Use VisumWay and
get yourself set up on this computer.” See [setup](../SETUP.md) and the
[Windows bundle guide](../docs/WINDOWS_BUNDLE.md).

Windows x64 and signed-in Codex are the tested beta path. Other hosts
and platforms have different capabilities. See the
[verification record](../docs/VERIFICATION.md).
