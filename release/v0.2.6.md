# VisumWay v0.2.6

**Give your AI eyes and a body.** VisumWay sets up shared, local computer
tools so an agent can read app state, follow a window, and verify what
happened after it acted.

- **Set it up once.** A local agent detects the OS, prepares the shared
  tools, and verifies what the computer supports. Codex, Claude Code and
  other compatible agents can reuse the installation through CLI or MCP.
- **Read app controls directly on Windows.** In two matched Calculator
  trials, Codex finished in **23.3 s vs. 34.3 s** using screenshots, with
  the same keyboard actions. [Benchmark and raw timings](https://github.com/jay-showforge/VisumWay/blob/v0.2.6/docs/BENCHMARK.md).
- **Follow a window during a task.** The Windows helper delivers window
  frames on demand and keeps a short history of changes during an active
  watch. A live test recovered a state that lasted just 552 ms.
- **Keep one agent in charge of alerts.** The first named installer owns
  optional background notifications. Other agents share the tools. Wakes
  are opt-in, and VisumWay uses zero model tokens while idle.

## Get started

**Windows x64:** Download `VisumWay-v0.2.6-windows-x64.zip` from Assets.
It includes the wheel, native helper, and an offline installer. The
attached `SHA256SUMS.txt` verifies the tested local build. Follow the
[Windows install guide](https://github.com/jay-showforge/VisumWay/blob/v0.2.6/docs/WINDOWS_BUNDLE.md).

Or give a local agent [the repository](https://github.com/jay-showforge/VisumWay)
and say, “Use VisumWay and get yourself set up on this computer.” The
shared core also installs from source on macOS and Linux. This preview’s
live desktop validation focused on Windows. See the
[platform matrix](https://github.com/jay-showforge/VisumWay/blob/v0.2.6/docs/PLATFORM_MATRIX.md)
for support and verification by OS.
