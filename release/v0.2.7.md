VisumWay v0.2.7 updates the project’s license and refreshes the offline
Windows x64 bundle.

## Tested behavior

Hosted unit tests and CLI/MCP checks passed on Windows, macOS, and Linux.
The macOS runner captured a desktop frame. Live Windows 11 tests recorded
in earlier builds cover direct app-control reads, buffered window capture,
and a real Codex wake that produced a native alert. Interactive macOS and
Linux sign-in, crash delivery, and notifications are pending.

## Install

Download the **Windows x64 ZIP** and **SHA256SUMS.txt** from Assets. The
ZIP includes the wheel, native capture helper, and offline installer.
See the [Windows install guide](https://github.com/jay-showforge/VisumWay/blob/v0.2.7/docs/WINDOWS_BUNDLE.md)
for checksum and build attestation commands.

Or give your local agent [the setup guide](https://github.com/jay-showforge/VisumWay/blob/v0.2.7/SETUP.md)
and say, “Use VisumWay and get yourself set up on this computer.” See
the [platform matrix](https://github.com/jay-showforge/VisumWay/blob/main/docs/PLATFORM_MATRIX.md)
for capabilities by operating system.
