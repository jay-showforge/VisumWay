VisumWay sets up the local tools that let a desktop agent check its work
and enables the computer to wake the chosen agent when an eligible event
occurs. This patch updates the documentation in the source release and
Windows bundle.

## What the tests cover

- **Windows:** Live Windows 11 tests exercised app-control reads, a
  buffered window watch, and real Codex crash wakes with native alerts
  and chat resume.
- **macOS:** Hosted CI exercised the CLI/MCP smoke checks and captured
  a desktop frame. Sign-in startup, native event delivery, and the full
  alert flow still need an interactive Mac test.
- **Linux:** Hosted CLI/MCP checks and a shared-setup smoke test under
  Ubuntu on WSL passed. Native Linux desktop and alert validation is pending.

The Calculator timings are an exploratory two-pair pilot. The
[verification record](https://github.com/jay-showforge/VisumWay/blob/v0.2.8/docs/VERIFICATION.md)
identifies the environment and version for each result.

## Install and verify

Download **VisumWay-v0.2.8-windows-x64.zip** and **SHA256SUMS.txt** from
Assets. The ZIP contains the wheel, native helper, and offline installer.
[Windows installation and verification](https://github.com/jay-showforge/VisumWay/blob/v0.2.8/docs/WINDOWS_BUNDLE.md)

For source setup, give your agent the repository and ask it to set up
VisumWay on your computer.
[Agent setup](https://github.com/jay-showforge/VisumWay/blob/v0.2.8/SETUP.md)
